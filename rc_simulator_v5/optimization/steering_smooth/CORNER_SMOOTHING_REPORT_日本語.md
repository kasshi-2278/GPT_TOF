# コーナーの滑らかさ評価

## 変更内容

`optimization/straight_score.py` にコーナー平滑度を評価する指標を追加しました。走行ログから実際の操舵角速度と操舵角加速度（操舵ジャーク）を計算し、車速8 cm/s以上かつヨーレート4度/s以上の旋回中だけを、移動距離で重み付けして採点します。

新しい加点は最大100点です。3周を完走し、衝突とプログラムエラーがない走行に限って加算します。操舵角速度12度/s以下・ジャーク80度/s²以下なら各指標の品質を満点とし、60度/s・600度/s²以上は0点として、その間を線形に採点します。直進や停止を増やしても加点されません。従来の衝突・完走・壁接近を含む走行評価は変更していません。

## シミュレーション

基準コントローラーを同じコース・開始条件（seed 7、センサーノイズなし）で再実行しました。3周を401.32秒で完走し、衝突0、危険接近0、急操舵0、蛇行3、不要停止0でした。旋回距離は28.80 m、平均操舵角速度17.60度/s、平均操舵ジャーク60.99度/s²、コーナー平滑度0.834770でした。

従来のスコア式・直進加点・減速ペナルティ・時間加点の合計は954.14点で、新しいコーナー加点83.48点を加えた総合スコアは**1037.61点**です。

操舵レートの引き下げ、追加フィルター、追従先読み距離の増加など17条件を比較しました。複数の強めの平滑化条件は基準条件で安全停止または3周未完走となり、短いフィルター条件は完走したものの操舵平滑度が基準よりわずかに低下しました。そのため、既存コントローラーの操舵レート・加速度制限を保ち、完走と安全性を損なう制御変更は採用していません。現在の制御は急な変化を制限しており、今回の採点はその実測された旋回の滑らかさを加点します。
