# 操舵の平滑化と直進加点：100条件の比較

起動時のプログラムを `examples/sonic_drive_smooth.py` に変更しました。FTG・ピュアパシュート・安全回避を維持し、通常時の操舵出力に変化速度と変化速度の増減を制限する段階を追加しました。近接回避と測距異常による停止は遅延させません。controllerの入力は５つの超音波距離とdtだけです。以前の版は `Previous_Best.py` と `examples/sonic_drive_follow_gap.py` に残しています。

## 事前に固定した新スコア

従来の完走・衝突・壁接近・急操舵・蛇行・停止・時間のスコアは変更せず `original_score` として記録します。今回ユーザー指定の直進加点を別項目にしました。

`新スコア = 従来スコア + 300 × 適格直進距離 / 総移動距離`（直進加点は３周完走時のみ）

直進区間は実際の操舵角が±２度以内、ヨーレート６度/秒以下、速度５cm/s以上を１秒以上・20cm以上連続した区間です。停止で時間を延ばしても加点されず、未完走には加点しません。加点は最大300点です。算式・閾値は比較前に `rules.json` と `optimization/straight_score.py` で固定し、候補に合わせて変更していません。評価の位置・方位・移動距離を走行プログラムには渡しません。衝突判定・コース・壁座標・車体サイズ・３周判定も変更していません。

## 100試行と選択

100試行（比較用の再実行を含む、ソースSHA-256は99種類）を実施しました。単純な全走行平滑化、操舵速度・変化速度の制限、低域フィルター、デッドバンド、コーナー検知距離と旋回量、壁端回避の検知タイミング、センサー平滑化などを比較しました。強い平滑化には回避の遅れによる衝突・停止があり不採用です。

衝突・危険接近・エラーなしで基準条件の３周を完走した候補は6件。最大新スコアは79番と83番の同点で、より小さい操舵速度上限の79番を採用しました。選択条件は通常時の操舵速度上限140%/秒、変化速度の増減上限8000%/秒²、追加低域フィルター０秒、デッドバンド０、安定測距時の壁端回避Accel上限14%・距離係数0.45です。強い平滑化を採用したものではなく、完走を維持できた穏やかな出力制限です。

直進割合が約2.12ポイント増え、蛇行が１回減り、新スコアは12.67点改善しました。３周は約3.72秒遅くなります。実測の最大操舵速度は両版とも44.8度/秒で、全操舵変化量は最終版で約0.36%増えており、あらゆる滑らかさ指標が改善したわけではありません。基準条件での強いコーナー平滑化や急操舵数の改善は実証できていません。選択した穏やかな出力制限は、基準条件の操舵を大幅には変えず、壁端回避の低速制限と組み合わせて直進・蛇行の評価を改善しました。

## 最終ソースの追加10回検証

実際の外部Pythonワーカーで10回実行しました。完走率20%（2/10）、衝突率０%、平均新スコア-17.72、最低-385.20、最高722.22です。完走した２回の平均３周時間は399.14秒、全試行の平均評価時間は185.99秒（未完走の停止までの時間を含む）です。平均危険接近0.60回、平均急操舵0.00回、平均蛇行3.00回、平均不要停止0.30回でした。

成功した２回はノイズなし・同じ開始位置と向きの決定論的な基準条件の繰り返しです。ノイズと開始姿勢を変えた８条件では３周安定完走は未達です。初期版も完走2/10・衝突0・危険接近合計6で、最終版でも同数を維持しました。全10回の平均新スコアは初期版-20.25→最終版-17.72です。実機の完走を保証するものではありません。

完走確認された条件は、現在のcourse_1030、車体28×20cm、ホイールベース17cm、５つの既定HC-SR04取付位置、開始位置(85,200)cm・南向き、センサーノイズ０、20Hz制御です。これらの座標は評価と開始設定だけに使用し、走行プログラムには含めません。ノイズ耐性、壁端の識別、全操舵量とコーナーの滑らかさに問題が残っています。

## ファイルと再現

`history.csv/json` に全100試行、`successful_candidates.json` に安全に完走した候補、`Best_Version.py` に最終ソース、`final_validation.csv/json` と `final_logs` に最終ソース10回の結果と測距ログ、`selection.json` に選択とSHA-256を保存しています。旧スコア最高版も既存の `optimization/divider_flow/Score_Best_Version.py` に保持しています。

再検証：`python -m optimization.validate_smooth`。単一走行：`python -m optimization.evaluate_smooth examples/sonic_drive_smooth.py --external --name my_smooth`。４つの `search_*.py` が候補を構成する再現用スクリプトです。

GUIに参考の直進割合と、３周完走時にだけ確定する直進加点を追加しました。162件のテスト、直進加点の停止・未完走・短い区間の除外、操舵出力制限、近接時に回避を遅らせないこと、２タブの観察画面とリセットを確認しました。動画は最終ソースを実ワーカーで実行した連続３周の３倍速です。
