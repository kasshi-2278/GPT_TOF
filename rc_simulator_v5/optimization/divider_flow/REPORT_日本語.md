# 仕切り減速・超音波判断表示の変更

車視点と表示用の仮想カメラ処理を削除し、Vキー／「超音波・判断 V」で超音波５方向・判断と障害物マッピングの２画面を表示します。
色の線は測距値、緑の矢印はコントローラーの目標方向、白点線は出力された操舵指令の曲率です。操舵の遅れを含む実車の未来軌跡を保証する線ではありません。最大測距は未検出として表示し、安全停止時は進行矢印を消します。目標角度は状態文字列の表示専用タグで外へ出力します。５距離とdt以外の情報はcontrollerへ渡しません。

## 減速原因と最終案

斜め距離45cm以内で仕切り回避に入り、Accel上限14%と緩い距離比例係数により、前方が開いていても強く低速化していました。上限20%／距離係数0.6の案では、基準条件で仕切り回避状態の平均速度14.464→17.718cm/s（上段y=200〜330cmの評価専用区間）、回避状態の観測回数51→34（20Hz）、３周399.138→395.417秒でした。これは「すべての仕切りで減速ゼロ」を達成したものではありません。安全に必要な減速は残します。

71候補を比較しました。速度を大幅に増やす、広い通路にも高速ギャップ制御を適用する、早期回避するなどの候補には衝突・安全停止があり、不採用です。単純に速度上限を上げた案もノイズ条件で危険接近が増えたため不採用です。最終案では起動直後の低速６サンプルで５センサーの二階差分最大が0.25cm未満の場合にのみ回避制限を緩め、測距が不安定なら従来の慎重な制御を使います。これは起動時の測距品質の確認であり、その後のノイズ増加を保証する診断ではありません。実機の測距周期やノイズで再調整が必要です。非常停止閾値・コース・障害物・衝突判定・評価式は変更していません。

## 最終プログラムの外部ワーカー10回検証

基準条件の連続３周は131.271 / 132.047 / 132.100秒、合計395.417秒。衝突0、危険接近0、急ハンドル0、不要停止0、蛇行9でした。従来は合計399.138秒・蛇行8です。TOTAL SCOREは520.85→514.55で、速度は改善しましたが蛇行１回増により総合スコアは低下しています。従来の最高スコア版をScore_Best_Version.pyとPrevious_Best.pyに保持し、今回の減速軽減版はBest_Version.pyに保持しました。

追加10回は３周完走2/10、衝突0/10、危険接近合計6で、従来と同数です。２回の成功はノイズなし基準条件の繰り返しで、８回のノイズ・開始姿勢変更条件は安全停止です。安定した実機完走やノイズ耐性はまだ未達です。安全性を保ったまま全仕切りを高速で通過するには、疎な５方向測距での壁端の識別・回避とノイズ耐性に追加改善が必要です。

comparison.csvは71候補、program_final_validation.csv/jsonは最終ソース10回の記録、final_logsはその測距・走行ログです。selection.jsonに選択と最終ソースのSHA-256を保存しました。独立に３回リセットして合計した値ではなく、同じ車・controller状態で連続３周を計測しています。
