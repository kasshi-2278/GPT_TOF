# 仕切り付近の壁沿い走行

## 変更

走行プログラムは、左右斜めセンサーと側方センサーで平行壁を確認し、側方エコーが近距離で連続している間だけ、その壁を追従基準として保持します。前方が開き、反対側の斜めセンサーが仕切り端を検出した場合は、前回の壁向きと現在の側方距離から操舵を補正し、速度を維持します。

壁の反射が連続しない場合、車体が旋回状態の場合、前方が開いていない場合は既存の回避・減速制御に戻ります。測距値だけを使い、地図や位置、ルート情報は使いません。

## 結果

基準条件の連続3周では、仕切り端付近の1秒間の平均速度が **7.50 cm/s から 27.25 cm/s** に上がり、その区間で約27 cm/sを保ちました。仕切り端付近の最小クリアランスは **15.79 cm から 13.08 cm** に狭まりましたが、衝突・危険接近の判定はありませんでした。

| 指標 | 元版 | 壁追従版 |
| --- | ---: | ---: |
| 3周完走時間 | 399.138秒 | 401.321秒 |
| 評価スコア | 520.85 | 568.65 |
| 蛇行回数 | 8 | 3 |
| 衝突 / 危険接近 | 0 / 0 | 0 / 0 |
| 仕切り区間の平均速度 | 7.50 cm/s | 27.25 cm/s |

直線ボーナスと減速ペナルティも加えたスコアは **711.96 から 755.46** になりました。直線走行率は67.12%から64.89%に少し下がりましたが、避けられる減速ペナルティが10.26点から7.85点に減り、評価スコアは上がりました。

同じ10条件で比較した場合、完走は両版とも2/10、衝突は0/10でした。壁追従版は危険接近の平均が0.6回から0.5回、最低クリアランスの平均が8.71 cmから9.82 cm、蛇行の平均が3回から2回に改善しました。一方、完走率は上がっていません。10条件中、開始条件やセンサー誤差を加えた8条件では完走できず、ロバスト性には課題が残ります。

## 検証データ

- `divider_wall_follow_v5.csv`: 10試行の一覧
- `divider_wall_follow_v5.json`: 各試行の詳細と集計

安全停止と緊急回避は残しています。壁追従を無条件に適用すると、ずれた開始位置や測距ノイズで危険接近や衝突が出たため、連続した壁エコーを確認できた場合に限るガード付き制御にしています。
