# 周回時間の加点

合計 `race_score = original_score + straight_bonus + time_bonus`。
時間ボーナスは `max(0,600 - ３周合計秒)`、衝突・プログラムエラーなしの３周完走時のみ。停止・未完走・衝突で加点されません。10分以上の時間加点は０ですが、従来の時間ペナルティが残るため、同じ他指標なら速いほど合計スコアが高くなります。走行判断や安全基準は変更していません。

既存100試行を再採点した結果、79番が最高923.080707点（従来520.85＋直進201.369199＋時間200.861508）でした。選択プログラムは変更していません。最終10回の記録も再採点しましたが、追加の物理シミュレーションを実行したと称するものではありません。完走2/10・衝突0という未解決のノイズ耐性は同じです。

再実行：`python -m optimization.time_bonus.rescore`。新たな走行の評価は `python -m optimization.evaluate_smooth examples/sonic_drive_smooth.py --external --name my_race` で `race_score` まで出力します。従来のレポートや動画の722.22は時間加点を導入する前の値として保持しています。
