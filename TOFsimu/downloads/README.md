# 走行プログラム配布

## 送付ログをもとにふらつきを抑えた走行プログラム

- [プログラムと使い方のZIP](TOFsimu_program_log_on_stop.zip)
- [Pythonプログラム単体](sonic_drive_v23_log_on_stop.py)
- [説明書](sonic_drive_v23_log_on_stop_README.txt)

ラズパイでZIPを解凍し、プログラムのあるフォルダをターミナルで開いて `python3 sonic_drive_v23_log_on_stop.py` を実行します。Enterで走行開始、Ctrl+Cで停止します。停止後、作業フォルダにTXTとJSONLの走行ログが保存されます。操舵や判断の分析にはJSONLをこのチャットに添付してください。

今回のログでは、斜め前の近接判定が1回ごとに解除・再発火し、逆方向へ切り返す様子が見えました。距離値の平滑化、斜め前判定2回・解除3回の連続確認、旋回最低時間と解除後の短い反転抑制、旋回指令±45を追加しています。GPIO・センサー・PWM初期設定および実機入出力は変更していません。

送付されたセンサー列を使った再生比較では操舵の総変化量が約30%減り、強い符号反転は6回から3回に減りました。一方、TOFsimuの旧幾何モデルでスタート1から試すと、接触なしで約40.4秒・15.6m走行した後に後退5回で停止し、1周はできていません。実機との距離・車体モデルの差があるため、これは実機完走の確認ではありません。
