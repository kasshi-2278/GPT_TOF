# TOFsimu 配布パッケージ

[シミュレータZIPをダウンロード](https://github.com/kasshi-2278/GPT_TOF/raw/refs/heads/main/TOFsimu/downloads/TOFsimu_simulator.zip)

現行コースと、元に戻した実機用v23（アクセル60・後退上限999）を収録しています。v24の修正案は含みません。

解凍後、Windowsは `START_WINDOWS.bat`、ラズパイ/macOS/LinuxはTOFsimuフォルダで `sh START_MAC_LINUX.sh` を実行してください。Python 3.8以降が必要です。画面で `sonic_drive_restored_v23.py` を選択すると実機用v23を試せます。

現在使用していた幾何射線モデルの互換実行です。後期HC-SR04音響モデルは未復元です。詳しくはZIP内の `README_PACKAGE_JA.txt` を参照してください。
