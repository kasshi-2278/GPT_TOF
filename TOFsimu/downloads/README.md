# 走行プログラム配布

## 送付ログを反映した、周回確認済みプログラム

- [プログラムと使い方のZIP](TOFsimu_program_log_on_stop.zip)
- [Pythonプログラム単体](sonic_drive_v23_log_on_stop.py)
- [説明書](sonic_drive_v23_log_on_stop_README.txt)

ラズパイでZIPを解凍し、プログラムのあるフォルダをターミナルで開いて `python3 sonic_drive_v23_log_on_stop.py` を実行します。Enterで走行開始、Ctrl+Cで停止します。停止後、作業フォルダにTXTとJSONLの走行ログを保存します。修正分析にはJSONLをこのチャットに添付してください。

走行ログの短周期の切り返しを抑えるため、距離フィルターを維持し、旋回解除を最低0.12秒・2回連続の確認にしました。送付されたセンサー列で再生比較すると、操舵総変化量は約35%減り、強い符号反転は6回から3回に減りました。GPIO・センサー・PWMの初期設定と実機出力換算は元プログラムと同一です。

この版はTOFsimuのスタート1から1周を完了しました。所要51.69秒、接触0、後退0回です。1周確認には図面から推定した4つの計測ゲートを使い、ゲート情報は走行判断には渡していません。シミュレーターは旧幾何モデルで、実機走行と後期HC-SR04音響モデルは未検証です。

## 既存のTOFsimuを1周判定対応にする

- [シミュレーター更新パッチ](TOFsimu_start1_one_lap_patch.zip)

ZIPを解凍し、中身を既存の `TOFsimu` フォルダへ上書きしてください。コース形状は維持し、周回数を数える4つの仮想ゲートと、スタート1・ログ付き走行プログラムの初期選択を追加します。ゲートは走行判断には使いません。
